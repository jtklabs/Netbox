Small count or classification chip. Square corners, 20px tall.

```jsx
<Badge tone="danger">4 overdue</Badge>
<Badge tone="brand">Tier 1</Badge>
<Badge tone="neutral" solid>12</Badge>
```

Badge is for counts and fixed classifications (tier, region, severity). Lifecycle state — Active, Pending, Expired — belongs to StatusPill, which is pill-shaped so the two never get confused in a table.
